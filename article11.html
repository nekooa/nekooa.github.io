我的桌面配置与脚本 · 二：kitty、fish、fastfetch 与 Noctalia

2026-11-14 · 约 12 分钟阅读 · # kitty # fish # fastfetch # Noctalia

上一篇写了 niri、Noctalia 的壁纸 Hook 和 SDDM 自动换壁纸，这一篇把剩下的部分补齐：kitty、fish、fastfetch，以及 Noctalia Shell v5 里我真正改过的设置。

和上一篇一样，这不是教程，是配置文件加上"为什么这么写"的记录。看见 /home/sagiriworld 就换成你自己的用户名。

环境#

项目 选择
发行版 CachyOS
窗口管理器 niri
Shell Noctalia Shell v5
终端 kitty
交互 Shell fish + Oh My Fish（kovial 主题）
系统信息 fastfetch
配色 Noctalia 壁纸取色（M3 content）

这套组合里最有意思的一点是：kitty、fastfetch、Noctalia 的配色其实是同一个来源，只有 fish 的配色是 kovial 主题自己的。所以从终端开始讲最顺。

kitty：配置几乎只写排版#

kitty 只有一个配置文件：~/.config/kitty/kitty.conf。我的全部内容如下，短到可以直接贴进文章。

# 字体 font_family FiraCode Nerd Font bold_font auto italic_font auto bold_italic_font auto font_size 10.0 # 背景 background_opacity 0.85 background_blur 30 # 光标 cursor_shape block cursor_color #ffffff cursor_blink_interval 0.5 cursor_stop_blinking_after 0 # Neovide 风格拖尾 cursor_trail 3 cursor_trail_decay 0.1 0.4 cursor_trail_start_threshold 2 # 性能 scrollback_lines 10000 include themes/noctalia.conf

逐项说明

  • font_family FiraCode Nerd Font：等宽 + Nerd Font 图标，fastfetch 的图标全靠它。
  • background_opacity 0.85 + background_blur 30：半透明 + 背景模糊；模糊是否生效取决于合成器，没效果不代表配置写错了。
  • cursor_shape block、cursor_color #ffffff：块状光标。颜色在主题文件里也有一份，那边优先。
  • cursor_blink_interval 0.5、cursor_stop_blinking_after 0：闪烁周期 0.5 秒，0 表示永不停止闪烁。
  • cursor_trail 3 / cursor_trail_decay 0.1 0.4 / cursor_trail_start_threshold 2：Neovide 风格的光标拖尾——长度 3 格，衰减 0.1→0.4，移动超过 2 格才出现。
  • scrollback_lines 10000：回滚缓冲行数，翻日志够用。
  • include themes/noctalia.conf：配色文件，由 Noctalia 自动生成，见下一节。

一眼可知，这份配置里几乎没有"功能"——没有自定义快捷键、没有标签栏样式、没有布局预设。因为我用 niri 管窗口，kitty 只需要当一个好看的、带一点视觉反馈的终端就够了。

配色不手写，交给 Noctalia

最后一行 include themes/noctalia.conf 是整份配置里最省事的一行。Noctalia 的模板系统会把当前壁纸的取色结果写成这个文件：

color0 #41474f color1 #ffb4ab color2 #94ccff color3 #b4c9df color4 #e8b5f5 color5 #b2c5ff color6 #cac2e2 color7 #c1c7d0 color8 #8b9199 color9 #ffcbc5 color10 #b7dbff color11 #dbd2ff color12 #f5c8ff color13 #ace1e1 color14 #f8d196 color15 #e1e2e6 cursor #e1e2e6 cursor_text_color #111417 background #111417 foreground #e1e2e6 selection_foreground #c1c7d0 selection_background #41474f active_border_color #94ccff inactive_border_color #41474f url_color #94ccff active_tab_foreground #003352 active_tab_background #94ccff inactive_tab_foreground #c1c7d0 inactive_tab_background #41474f cursor_trail_color #c1c7d0

也就是说，kitty 里没有任何一个颜色是我手写的。换壁纸 → Noctalia 重新取色 → 自动重写这个文件 → 新开的 kitty 就是新配色。排版归 kitty，颜色归桌面，这是我觉得最舒服的分工。

顺带一提，Noctalia 用的是 Material 3 的 m3-content 方案——从一张壁纸里推出一整套协调的颜色。这个站点也在模仿 Material 3，所以看起来应该挺眼熟（我是真的很喜欢 Material 3！）。

fish：三行配置，剩下的交给插件#

fish 的配置文件短得有点不像话：

# ~/.config/fish/config.fish set -g fish_greeting "" set -gx TERMINAL kitty fastfetch

三行：

  • fish_greeting ""：关掉 fish 自带的欢迎语。因为紧接着的 fastfetch 就是我的欢迎界面，没必要先说一句"欢迎使用 fish"再打印一大块信息。
  • TERMINAL kitty：给那些会读 $TERMINAL 的程序用。（其实这里有个小插曲，我以前用的 foot 终端，这里填的 foot，写这篇文章时才发现www）
  • fastfetch：每开一个交互终端就打印一次系统信息。代价是开终端会慢那么一点点；如果介意，可以包一层判断，只在交互式会话里跑。

插件：两套管理器并存

我的 fish 里其实有两套插件机制，各管各的：

# ~/.config/fish/conf.d/omf.fish —— Oh My Fish 自动生成，负责主题 set -q XDG_DATA_HOME and set -gx OMF_PATH "$XDG_DATA_HOME/omf" or set -gx OMF_PATH "$HOME/.local/share/omf" source $OMF_PATH/init.fish # ~/.config/fish/fish_plugins —— fisher 管理，负责 nvm jorgebucaran/nvm.fish

OMF 只用来加载 kovial 主题，fisher 只用来装 nvm.fish。两套系统同时存在不会打架，但升级或重装的时候要清楚谁管什么，别把一个插件装两遍——尤其是 nvm 这种会写 universal variables 的插件。

kovial 主题：直接改主题文件

kovial 是 OMF 的第三方主题，整个主题只有一个文件：

~/.local/share/omf/themes/kovial/functions/fish_prompt.fish

OMF 的路径规律就是 $OMF_PATH/themes/主题名/，当前启用哪个看 ~/.config/omf/theme。它的提示符原本是方角的，现在长这样：

原版用的是 ┌── 和 └──▶，我在这个文件上改了三处细节，直接看 diff 最清楚：

--- a/functions/fish_prompt.fish +++ b/functions/fish_prompt.fish @@ -1,5 +1,5 @@ function hostname - printf '%s[%s]%s' (set_color -o green) $hostname (set_color normal) + printf ' %s(%s)%s' (set_color -o green) $hostname (set_color normal) end @@ -32,13 +32,13 @@ if set -q _flag_f - printf '┌──' + printf '╭──' else if set -q _flag_s - printf '└──▶ ' + printf '╰──▶ ' end end function fish_prompt - printf '%s%s as %s in %s %s %s' (arrow -f) (hostname) (user) (custom_prompt_pwd) (git_branch) (arrow -s) + printf '%s%s as %s in [%s] %s %s' (arrow -f) (hostname) (user) (custom_prompt_pwd) (git_branch) (arrow -s) end

对应三处：hostname 从 [host] 变成 (host) 并多一个前导空格；上下箭头换成圆角；当前目录用 [ ] 包起来。

要注意 OMF 装主题其实是 git clone 到 themes/ 下的，omf update 或重装主题时，这类未提交的本地改动有被覆盖或冲突的风险。最好改完复制成自己的主题名。

fastfetch：用 custom 模块拼一张卡片#

fastfetch 的配置是 JSONC（JSON + 注释），文件在 ~/.config/fastfetch/config.jsonc。我不喜欢默认那种"左边 logo、右边一长串 key: value"的布局，所以用 custom 模块画了四条分组框，把信息按 硬件 / 软件 / 桌面 / 时长 分开。

分组 模块 内容
硬件 host / cpu / gpu / memory / disk 设备型号、CPU、GPU、内存、磁盘
软件 os / kernel / bios / packages / shell 系统、内核、BIOS、包数量、Shell
桌面 lm / wm / wmtheme / terminal 显示管理器、窗口管理器、主题、终端
时长 command / uptime 系统安装天数、开机时长

几个细节

  • 边框是画出来的，不是组件。custom 模块的 format 里直接写 ╭────╮，前面拼上 ANSI 颜色（\u001b[32m 是绿色）。四组分别是绿、黄、蓝、品红，靠等宽字体对齐。（这里的 ANSI 颜色实际上会被 noctalia 覆盖）
  • keyWidth: 15 是灵魂。所有 key 都被填到 15 个字符宽，右边的值才会整齐地站成一列；keyColor 和分组框同色，视觉上就是一组。
  • 图片 logo 走 kitty 图形协议。"type": "kitty" 只在支持该协议的终端里显示图片；换到 foot / 传统终端要改成 ASCII 或其它 type，否则那块会空着。
  • 图标是 Nerd Font 私用区字符。字体不对就会变成方块或问号——这也是为什么 kitty 的字体必须是 Nerd Font。

Noctalia Shell v5：改过的设置#

Noctalia 的配置分两层：~/.config/noctalia/ 下的 *.toml 是手写层（按文件名排序合并），~/.local/state/noctalia/settings.toml 是 GUI 覆盖层，最后加载、优先级最高；两层都会热重载。

所以「设置里改了、config.toml 却没变」是正常的——改动写进了 settings.toml。

主题：从壁纸里取色

[theme] builtin = "Ayu" mode = "dark" shell_mode = "dark" source = "wallpaper" wallpaper_scheme = "m3-content" [theme.templates] enable_builtin_templates = true enable_community_templates = true builtin_ids = [ "alacritty", "btop", "cava", "emacs", "foot", "gtk3", "gtk4", "ghostty", "helix", "hyprland", "kcolorscheme", "kitty", "labwc", "mango", "niri", "qt", "scroll", "starship", "sway", "umbriel", "wezterm", ]

这一段解释了两件事：

  • source = "wallpaper" + wallpaper_scheme = "m3-content"：配色从壁纸里推出来。
  • builtin_ids 里的每一项都是一个"把当前配色写出去"的模板：kitty、foot、btop、cava、starship…… 上一篇里 kitty 的 themes/noctalia.conf、状态栏颜色等等都是这里统一生成的。

这也是为什么我几乎不在各个程序里手写颜色——壁纸是唯一的源头。

Bar 与 Dock：厚度、透明度与 widget 胶囊

[bar.default] position = "top" thickness = 34 padding = 14 margin_edge = 0 margin_ends = 0 radius = 0 background_opacity = 0.49 compositor_blur = true capsule = true capsule_fill = "surface" capsule_opacity = 0.4 capsule_thickness = 0.76 font_weight = 500 start = [ "clock", "active_window" ] center = [ "workspaces" ] end = [ "tray", "clipboard", "network", "bluetooth", "battery", "volume", "brightness", "mpvpaper" ] [dock] enabled = true position = "bottom" icon_size = 48 magnification = true magnification_scale = 1.45 background_opacity = 0.65 margin_edge = 10 radius = 20 show_running = true smart_auto_hide = true pinned = [ "chromium", "bettbox", "localsend", "qq", "lmms", "code-oss", "deepseek-harness" ]
  • Bar 是贴着顶边的一条。margin_edge = 0、margin_ends = 0、radius = 0，所以它从屏幕左边缘一直铺到右边缘，没有圆角，也不是浮动条；padding = 14 是 bar 两端到 start / end 区的内边距。
  • 胶囊是每个 widget 自己的。capsule = true 不是把整条 bar 做成胶囊，而是给 bar 上的每个 widget各套一层：capsule_fill = "surface" 填 surface 色、capsule_opacity = 0.4、capsule_thickness = 0.76（占 bar 厚度的 76%）；没写 capsule_radius，所以自动取 pill 圆角。
  • 背景半透明 + 模糊。background_opacity = 0.49，compositor_blur = true 向合成器声明一块模糊区域，让壁纸透上来。
  • 三段式布局。start 放时间和当前窗口，center 放工作区，end 放托盘、剪贴板、网络、蓝牙、电池、音量、亮度和 mpvpaper——bongocat 那只猫已经从这一排移掉了。
  • Dock 开了放大和运行指示。magnification + scale = 1.45，鼠标划过时图标会放大；show_running = true 给正在运行的应用加小圆点。
  • pinned 是固定项。固定的是应用 id / 名称，重装应用后如果对不上号，删掉重 pin 一次就行。

Hook：壁纸变化 → SDDM

上一篇那个 SDDM 壁纸同步脚本，就是在这里挂上：

[hooks] wallpaper_changed = "~/.local/bin/sddm-wallpaper-sync"

小结#

四件东西，四种性格：kitty 只管排版，颜色全交给桌面；fish 几乎没有配置，重活都给了插件；fastfetch 是纯粹的"排版软件"；Noctalia 则是把壁纸、配色、模板串起来的那个枢纽。

它们之间真正的粘合剂是 Noctalia 的模板系统——一份壁纸配色，同步到终端、状态栏、btop、cava。配置越少，越不容易坏；颜色越统一，越不需要调。

配置写到一定程度，追求的就该是"半年不用打开它"。
